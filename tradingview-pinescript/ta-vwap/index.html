01

What is ta.vwap in Pine Script?

ta.vwap is a built-in function in Pine Script that calculates the Volume Weighted Average Price, a crucial indicator used by institutional traders to determine the true average price of an asset for the current trading session. VWAP gives more weight to prices with higher volume, providing a more accurate representation of fair value.

  • ▸ Fair Value: Price trading around VWAP is considered "fair value" for the day.
  • ▸ Support/Resistance: VWAP frequently acts as dynamic support or resistance.
  • ▸ Trend Confirmation: Price above VWAP indicates bullish sentiment, below indicates bearish.
  • ▸ Anchored VWAP: Can be anchored to specific points for multi-day analysis.

Basic ta.vwap Implementation

pine-script@terminal 
//@version=5
indicator("VWAP", overlay=true)

// Input parameters
useStdDev = input.bool(true, title="Show Standard Deviation Bands")
stdDevMultiplier = input.float(2.0, title="StdDev Multiplier", minval=0.1, step=0.1)

// Calculate VWAP using typical price (hlc3)
vwapValue = ta.vwap(hlc3, volume)

// Plot VWAP
plot(vwapValue, title="VWAP", color=color.purple, linewidth=2)

// Optional: Standard Deviation Bands
if (useStdDev)
    var float sum_tp_volume = 0.0
    var float sum_volume = 0.0
    var float sum_sq_diff_volume = 0.0
    
    if ta.change(time("D"))
        sum_tp_volume := 0.0
        sum_volume := 0.0
        sum_sq_diff_volume := 0.0
    
    tp = (high + low + close) / 3
    sum_tp_volume := sum_tp_volume + (tp * volume)
    sum_volume := sum_volume + volume
    currentVwap = sum_volume != 0 ? sum_tp_volume / sum_volume : vwapValue
    
    if not na(currentVwap) and volume > 0
        sum_sq_diff_volume := sum_sq_diff_volume + (math.pow(tp - currentVwap, 2) * volume)
    
    stdDev = sum_volume != 0 ? math.sqrt(sum_sq_diff_volume / sum_volume) : 0.0
    upperBand = currentVwap + (stdDev * stdDevMultiplier)
    lowerBand = currentVwap - (stdDev * stdDevMultiplier)
    
    plot(upperBand, title="Upper Band", color=color.new(color.blue, 50), linewidth=1)
    plot(lowerBand, title="Lower Band", color=color.new(color.blue, 50), linewidth=1)
    fill(plot(upperBand), plot(lowerBand), color=color.new(color.blue, 95))

Use VWAP to confirm trend direction.

//@version=5
strategy("VWAP Trend Confirmation", overlay=true)

// Calculate VWAP
vwapValue = ta.vwap(hlc3, volume)

// Trend confirmation
isBullish = close > vwapValue and vwapValue > vwapValue[1]
isBearish = close < vwapValue and vwapValue < vwapValue[1]

// Entry signals
longCondition = ta.crossover(close, vwapValue) and isBullish
shortCondition = ta.crossunder(close, vwapValue) and isBearish

if (longCondition)
    strategy.entry("Long", strategy.long)
if (shortCondition)
    strategy.entry("Short", strategy.short)

// Exit when trend reverses
strategy.close("Long", when=ta.crossunder(close, vwapValue))
strategy.close("Short", when=ta.crossover(close, vwapValue))

Key ta.vwap Parameters

Key ta.vwap Parameters

source (hlc3): The price source used for calculation. hlc3 (high+low+close/3) is most common.
volume: The volume series for weighting.
Return Value: ta.vwap returns the VWAP value for the current bar.
Session Reset: VWAP resets at the beginning of each trading session.
Anchored VWAP: Can be anchored to specific points for multi-day analysis.

06

Optimizing ta.vwap for Better Performance

To get the most out of ta.vwap in your Pine Script strategies:

  • ▸ Use Appropriate Source: hlc3 is most common, but you can use hlc4 for more weighting on close.
  • ▸ Combine with Volume: VWAP's effectiveness depends on accurate volume data.
  • ▸ Add Standard Deviation Bands: Bands around VWAP help identify overextended moves.
  • ▸ Higher Timeframe Context: Consider VWAP from higher timeframes.
  • ▸ Anchored VWAP: Anchor to significant events for more relevant analysis.
07

Pro Tip: Customizing ta.vwap

Pro Tip: Customizing ta.vwap

You can create custom VWAP variations by using different source prices, adjusting the session reset point, or using volume-weighted moving averages for different periods.

08

Common ta.vwap Pitfalls to Avoid

  • ▸ Using for Long-Term Analysis: VWAP resets daily, making it unsuitable for long-term analysis.
  • ▸ Ignoring Volume: VWAP's reliability depends on accurate volume data.
  • ▸ False Breakouts: Wait for confirmation before trading VWAP breakouts.
  • ▸ Over-reliance: Use VWAP in combination with other indicators.
  • ▸ Incorrect Source: Using the wrong price source can reduce effectiveness.
