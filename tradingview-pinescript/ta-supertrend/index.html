What is ta.supertrend in Pine Script?

ta.supertrend is a powerful built-in function in Pine Script that implements the Supertrend indicator, a trend-following tool developed by Olivier Seban. The Supertrend indicator combines Average True Range (ATR) with price action to identify the direction of a trend and generate buy and sell signals. It is widely regarded as one of the most effective trend-following indicators available in TradingView, offering clear visual signals that are easy to interpret and implement in trading strategies.

The Supertrend indicator calculates two values: a trend value and a direction value. The trend value represents the current Supertrend level, which acts as dynamic support or resistance depending on the market direction. The direction value indicates the current trend direction, where 1 typically represents an uptrend and -1 represents a downtrend. This dual output makes ta.supertrend exceptionally useful for both trend identification and signal generation.

One of the key advantages of the Supertrend indicator is its ability to adapt to changing market conditions through its ATR-based calculations. Unlike fixed support and resistance levels, the Supertrend moves with the market, adjusting its levels based on recent volatility. This dynamic nature makes it particularly effective in trending markets, where it can help traders stay in trades for longer periods and avoid premature exits.

  • ▸ Trend Direction: Identifies whether the market is in an uptrend or downtrend.
  • ▸ Dynamic Support/Resistance: Provides levels that move with price action.
  • ▸ Buy/Sell Signals: Generates clear entry and exit signals based on trend changes.
  • ▸ Volatility Adjustment: Automatically adjusts to changing market volatility through ATR.
  • ▸ Risk Management: Can be used for stop-loss placement and position sizing.
02

ta.supertrend Function Signature and Parameters

pine-script@terminal 
[supertrend, direction] = ta.supertrend(high, low, close, atrPeriod, multiplier)

// Parameters:
// high        - Series of high prices
// low         - Series of low prices
// close       - Series of close prices
// atrPeriod   - The period used for ATR calculation (default: 10)
// multiplier  - The multiplier used to determine the band width (default: 3.0)

// Returns:
// [supertrend, direction] - Tuple containing:
//   supertrend: The Supertrend value (acts as dynamic support/resistance)
//   direction:  1 for uptrend, -1 for downtrend

// Direction Values:
// direction = 1   - Bullish trend (price is above Supertrend)
// direction = -1  - Bearish trend (price is below Supertrend)
// direction = 0   - Neutral/Transition state (rarely occurs)

// Signal Generation:
// Buy Signal  : direction changes from -1 to 1
// Sell Signal : direction changes from 1 to -1

Understanding ta.supertrend Direction Values

The direction value returned by ta.supertrend is the key to generating trading signals. Understanding what each value means is crucial for implementing effective strategies:

  • ▸ direction = 1 (Uptrend): Price is trading above the Supertrend line. The Supertrend acts as dynamic support. Look for buy opportunities and hold long positions. This is considered a bullish market condition.
  • ▸ direction = -1 (Downtrend): Price is trading below the Supertrend line. The Supertrend acts as dynamic resistance. Look for sell opportunities and hold short positions. This is considered a bearish market condition.
  • ▸ Direction Change (Signal): When direction changes from -1 to 1, it generates a Buy Signal. When direction changes from 1 to -1, it generates a Sell Signal. These changes are the primary entry and exit signals for Supertrend-based strategies.
  • ▸ Direction Validation: The direction value alone is not enough; it should be validated with price action and other indicators for higher probability trades.
  • ▸ Multiple Timeframes: Direction values can be analyzed across multiple timeframes to confirm trend strength and identify potential reversals.

Basic ta.supertrend Implementation

pine-script@terminal 
//@version=5
indicator("Supertrend Indicator", overlay=true)

// Input parameters
atrPeriod = input.int(10, title="ATR Period", minval=1)
multiplier = input.float(3.0, title="Multiplier", minval=0.1, step=0.1)

// Calculate Supertrend
[supertrend, direction] = ta.supertrend(high, low, close, atrPeriod, multiplier)

// Plot Supertrend
plot(supertrend, title="Supertrend", color=color.new(color.blue, 80), linewidth=2)

// Color Supertrend based on direction
plot(supertrend, title="Supertrend Direction", color=direction == 1 ? color.green : color.red, linewidth=2)

// Plot Buy/Sell Signals
plotshape(direction == 1 and direction[1] == -1, title="Buy Signal", location=location.belowbar, color=color.green, style=shape.triangleup, size=size.small, text="BUY")
plotshape(direction == -1 and direction[1] == 1, title="Sell Signal", location=location.abovebar, color=color.red, style=shape.triangledown, size=size.small, text="SELL")

// Alert conditions
alertcondition(direction == 1 and direction[1] == -1, title="Buy Alert", message="Supertrend Buy Signal")
alertcondition(direction == -1 and direction[1] == 1, title="Sell Alert", message="Supertrend Sell Signal")

Practical ta.supertrend Trading Strategies

1. Basic Supertrend Trend Following Strategy

This strategy enters trades when the Supertrend direction changes and exits when it reverses. 

//@version=5
strategy("Supertrend Trend Following", overlay=true, initial_capital=10000)

// Input parameters
atrPeriod = input.int(10, "ATR Period", minval=1)
multiplier = input.float(3.0, "Multiplier", minval=0.1, step=0.1)

// Calculate Supertrend
[supertrend, direction] = ta.supertrend(high, low, close, atrPeriod, multiplier)

// Entry signals
buySignal = direction == 1 and direction[1] == -1
sellSignal = direction == -1 and direction[1] == 1

// Execute trades
if (buySignal)
    strategy.entry("Long", strategy.long)

if (sellSignal)
    strategy.entry("Short", strategy.short)

// Exit signals
exitLong = direction == -1 and direction[1] == 1
exitShort = direction == 1 and direction[1] == -1

if (exitLong)
    strategy.close("Long")

if (exitShort)
    strategy.close("Short")

// Plot Supertrend with colors
plot(supertrend, title="Supertrend", color=direction == 1 ? color.green : color.red, linewidth=2)

// Plot signals
plotshape(buySignal, title="Buy Signal", location=location.belowbar, color=color.green, style=shape.labelup, text="BUY")
plotshape(sellSignal, title="Sell Signal", location=location.abovebar, color=color.red, style=shape.labeldown, text="SELL")

strategy("Supertrend with MA Confirmation", overlay=true, initial_capital=10000)

3. Supertrend with RSI Filter Strategy

This strategy combines Supertrend with RSI to avoid trading during overbought/oversold conditions. 

//@version=5
strategy("Supertrend with RSI Filter", overlay=true, initial_capital=10000)

// Input parameters
atrPeriod = input.int(10, "ATR Period", minval=1)
multiplier = input.float(3.0, "Multiplier", minval=0.1, step=0.1)
rsiLength = input.int(14, "RSI Length", minval=1)
overbought = input.int(70, "RSI Overbought", minval=1)
oversold = input.int(30, "RSI Oversold", minval=1)

// Calculate Supertrend
[supertrend, direction] = ta.supertrend(high, low, close, atrPeriod, multiplier)

// Calculate RSI
rsiValue = ta.rsi(close, rsiLength)

// Entry signals with RSI filter
buySignal = direction == 1 and direction[1] == -1 and rsiValue < overbought and rsiValue > oversold
sellSignal = direction == -1 and direction[1] == 1 and rsiValue > oversold and rsiValue < overbought

// Exit signals
exitLong = direction == -1 and direction[1] == 1
exitShort = direction == 1 and direction[1] == -1

if (buySignal)
    strategy.entry("Long", strategy.long)

if (sellSignal)
    strategy.entry("Short", strategy.short)

if (exitLong)
    strategy.close("Long")

if (exitShort)
    strategy.close("Short")

// Plot indicators
plot(supertrend, title="Supertrend", color=direction == 1 ? color.green : color.red, linewidth=2)
hline(overbought, "RSI Overbought", color=color.red, linestyle=hline.style_dashed)
hline(oversold, "RSI Oversold", color=color.green, linestyle=hline.style_dashed)

// Plot signals

Key ta.supertrend Parameters and Their Impact

Key ta.supertrend Parameters and Their Impact

atrPeriod (10): The period for ATR calculation. Lower values make the Supertrend more sensitive to price movements, generating more signals but also more false ones. Higher values make it smoother but less responsive.
multiplier (3.0): The multiplier for the band width. Higher values create wider bands, reducing false signals but potentially missing early trend changes. Lower values create tighter bands, generating more signals but with more noise.
direction (1 or -1): The trend direction indicator. 1 = Uptrend (buy signal), -1 = Downtrend (sell signal).
supertrend: The Supertrend value that acts as dynamic support/resistance.

07

Optimizing ta.supertrend for Better Performance

To get the most out of ta.supertrend in your Pine Script strategies, consider the following optimization techniques:

  • ▸ Parameter Optimization: Test different ATR periods and multipliers for your specific market and timeframe. Lower ATR periods (7-10) work well for shorter timeframes, while higher periods (14-20) are better for longer timeframes.
  • ▸ Multiplier Adjustment: The default 3.0 multiplier works well for most markets, but consider 2.5 for more sensitive signals or 4.0 for smoother signals.
  • ▸ Multi-Timeframe Analysis: Use Supertrend on higher timeframes for trend context and lower timeframes for entry signals.
  • ▸ Combine with Price Action: Look for support/resistance levels that align with Supertrend levels.
  • ▸ Use with Other Indicators: RSI, Moving Averages, and MACD can help filter signals and reduce false positives.
  • ▸ Backtest Thoroughly: Always backtest your Supertrend strategies across different market conditions before going live.
08

ta.supertrend vs Other Trend-Following Indicators

Understanding how ta.supertrend compares to other popular trend-following indicators can help you choose the right tool for your strategy:

  • ▸ vs Parabolic SAR: Both indicators provide dynamic stop-loss levels and trend direction. However, Parabolic SAR can be more sensitive to price movements and may generate more signals in choppy markets. Supertrend tends to be smoother and more reliable in trending markets.
  • ▸ vs Moving Averages: Moving averages are lagging indicators that smooth price data. Supertrend is more dynamic, adjusting to market volatility through ATR, making it more responsive to changing market conditions.
  • ▸ vs ADX: ADX measures trend strength but doesn't provide direction. Supertrend provides both direction and dynamic support/resistance levels, making it more actionable for trading.
  • ▸ vs MACD: MACD is a momentum indicator that can identify trend strength and direction. Supertrend is more visual and easier to interpret, especially for entry and exit signals.
  • ▸ Combined Use: Many successful traders combine Supertrend with moving averages or momentum indicators for higher probability trades.
09

Pro Tip: Multi-Timeframe Supertrend Trading

Pro Tip: Multi-Timeframe Supertrend Trading

For more robust signals, consider implementing multi-timeframe Supertrend analysis. Use a higher timeframe Supertrend for trend direction (e.g., Daily) and a lower timeframe Supertrend for entry signals (e.g., 1-hour). This approach can help you identify strong trends and enter at optimal points while reducing the impact of market noise.

10

Common ta.supertrend Pitfalls to Avoid

While the Supertrend is a powerful indicator, there are several common mistakes that traders should avoid:

  • ▸ Using in Sideways Markets: The Supertrend generates many false signals in range-bound or choppy markets. Consider using a trend filter before applying Supertrend strategies.
  • ▸ Ignoring Parameter Adjustment: Default parameters (10, 3.0) may not be optimal for all markets and timeframes. Always optimize for your specific trading conditions.
  • ▸ Over-reliance on Signals: Don't trade every Supertrend signal without confirmation. Use additional indicators and price action analysis for validation.
  • ▸ Using on Inappropriate Timeframes: Very short timeframes generate too many signals, while very long timeframes may miss significant moves.
  • ▸ Ignoring Market Context: Always consider the broader market conditions, news events, and fundamental factors that can impact price movements.
  • ▸ Not Using Stop-Loss: While Supertrend provides dynamic stop-loss levels, always use additional risk management techniques to protect your capital.
